# Zielbild der App

`index.html` zeigt, wie die App am Ende aussehen soll. Die Seite ist eine Vorschau ohne Funktion, alle Zahlen sind Beispielwerte.

Ansehen: https://pahlborn.github.io/Mustang-Car-Alignment/docs/zielbild/

Auf der Seite stehen alle Schritte der Phasen 0–22 und vier fertig ausgefüllte Beispielkarten. Über den Knopf „Erklärung“ öffnest du die Regeln für jede Karte, die Entscheidungen, die Bauweise und die offenen Punkte. Diese stehen nur dort und nicht noch einmal hier (Regel 4).
